Supported Rate-Limit Algorithms
Token Bucket (Default)
Allows burst traffic up to bucket capacity; steadily refills at configured rate (tokens/sec). Executed atomically in Redis Lua.
Sliding Window Log
Exact rolling time-window rate limiting using Redis Sorted Sets. Eliminates boundary bursts with precise timestamp accounting.
Leaky Bucket
Smooths bursts into a predictable outflow rate (requests/sec). Subunit leaking logic guarantees strictly capacity-bound queuing.
